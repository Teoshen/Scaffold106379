Overview

This repository contains reference files for identifying aquaporin genes in the scaffold draft genome assembly of Artemisia tridentata (Big Sagebrush). The assigned scaffold containing a likely aquaporin sequence analyzed here is scaffold106379. The files contained here include a .R file to mine, annotate, and validate the draft genome for aquaporin sequences, and .fa files containing the sequence of scaffold106379 and identified ORF sequences within this scaffold.

Description of Files

    Scaffold_106379_PIP.fa: File contains the original scaffold106379 amino acid sequence
    Scaffold106379_ORFs.fa: File contains all 24 ORFs found within scaffold106379
    Scaffold 106379 Script.R: File contains R script used to complete all computational analyses associated with this project
